# Beyt Dwarka

Website for Beyt Dwarka (Bet Dwarka) — the sacred island of Lord Krishna in Gujarat.

**Live:** [beytdwarka.vercel.app](https://beytdwarka.vercel.app/)

## Stack

- React 19
- Vite 8

## Getting started

```bash
yarn
yarn dev
```

| Command | What it does |
| --- | --- |
| `yarn dev` | Local development server |
| `yarn build` | Production build to `dist/` |
| `yarn preview` | Preview the production build |
| `yarn lint` | ESLint |
